# **App Name**: Ants Zoo Audit System

## Core Features:

- User Authentication: Simple login form with email and password authentication
- Zoo Dashboard: Display a list of zoos associated with the user. Zoo card shows "View Sites" button.
- Zoo Sites: Show all sites within the selected zoo. Site card contains a “View Enclosures” button.
- Enclosure List: List all enclosures within the selected site. Each enclosure has a “View Animals” button.
- Animal Verification: Display a list of animals within the selected enclosure. Each animal has a “Verify” button which toggles verification status.

## Style Guidelines:

- Primary color: Blue (#2196F3) for main elements such as app bar and buttons.
- Secondary color: Light Grey (#F5F5F5) for background and card elements to provide visual contrast.
- Accent: Green (#4CAF50) for the 'Verify' button and confirmation messages.
- Consistent font sizes for headers, subheaders, and body text to maintain readability.
- Use clear and consistent icons from Material Design icons for key actions and elements.
- Consistent spacing and padding to ensure readability.
- Use AppBar at the top for navigation and breadcrumbs.
